## Ricordi (`ricordi/`)

Foto vere prese da `per-boba/ricordi/immagini e video ricordi`, ridimensionate per il web.
Si gestiscono in `CONFIG.ricordi` (src, type `image`/`video`, caption).

Per aggiungere altre: copia il file in `assets/ricordi/` e aggiungi una riga in `CONFIG.ricordi`.
